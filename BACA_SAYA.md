# Tips Claude

Perpustakaan peribadi tips penggunaan Claude yang dikumpul dari Threads, disusun dan disemak.
Aplikasi web boleh-pasang (PWA) yang berfungsi luar talian.

## Pasang di telefon Android
1. Buka pautan GitHub Pages repo ini dalam **Chrome** (bukan Brave, supaya ciri Kongsi berfungsi).
2. Menu ⋮ → **Tambah ke skrin utama** / **Pasang aplikasi**.
3. Ikon **Tips Claude** muncul di skrin utama.

## Tab
- **Fokus**: tiga tip untuk dicuba minggu ini dan kemajuan belajar.
- **Pustaka**: carian, penapis kategori dan status, semua tip.
- **Peti Masuk**: simpan kata kunci, pautan dan tangkapan skrin. Dari Threads: Kongsi → Tips Claude.

## Rutin mingguan
Peti Masuk → **Sedia untuk Claude** → muat naik fail ke chat baharu dalam Projek "Tips Claude"
→ Claude mengemas kini `tips.json` → **Kosongkan peti masuk**.

Status belajar dan nota disimpan dalam telefon sahaja. Repo ini awam; ia hanya memuatkan senarai tip.
